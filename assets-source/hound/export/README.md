# Exportaciones de Hound

Carpeta preparada para futuras exportaciones revisadas, preferiblemente GLB o FBX.
Actualmente no hay exportaciones Meshy. Guardar cada entrega en su propia carpeta
de versión con texturas y recursos necesarios, procedencia y resultado de validación.

Las exportaciones existentes del motor siguen en `assets/characters/hound_rig/v17/`.
Un GLB o FBX generado requiere revisión visual y preparación para el pipeline de
Gloom antes de integrarlo; no es automáticamente una malla de producción aprobada.
Aplicar el [contrato H06](../../../docs/art/hound/H06-contrato-presupuesto.md).
