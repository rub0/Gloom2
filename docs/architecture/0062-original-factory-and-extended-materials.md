# ADR 0062: Original Factory and extended materials

## Status

Accepted. Implements milestones 59–61 from ADR 0061. Character/weapon
presentation, rigs, animation/VFX and graphical UI remain milestones 62–64.

## Decision

Convert legacy content offline without modifying the original checkout. A
restricted data parser reads map/archetype literals without executing Lua.
Resolve resources through the original resource groups and reject ambiguous
names with different contents. Normalize Ogre versions on copies, preserve
static submeshes/material assignments and reject skinning/animation explicitly.
Track original file hashes, conversion versions, bindings and diagnostics in
`assets/legacy/factory_scene.json`. Factory, Soul Reaper and v1.41 armour are
reproducible outputs; this does not assert conversion of all 133 legacy meshes.

Keep ten material texture slots and their UV transforms in the shared contract
from glTF through cooked scene version 3 and residency to Vulkan. Use glTF
specular, anisotropy, texture-transform and emissive-strength extensions, and
explicit `extras.gloom` for detail/lightmaps, UV motion and additive blending.
Legacy specular maps describe dielectric reflectance, not metallic/roughness.
Convert shininess to roughness with `(2/(shininess+2))^0.25`; this is an
approximation of the former shader. Bake original diffuse-times-glow semantics
into colored emission. Preserve linear/data versus sRGB semantics; reject a
source image reused with conflicting color/data/normal interpretations.

Use tangent-space GGX anisotropy, BC5 normal-Z reconstruction, alpha-aware
masked shadows and sorted blend/additive draws without depth writes. Enable
Vulkan independent blending explicitly. Per-draw shadow alpha textures must
use dynamic shader bindings: mutating a shared mutable binding invalidated
previously recorded Vulkan commands during acceptance and was corrected.

Bake one deterministic 32-pixel HDR cube from Factory and its lava with six
GGX-filtered mips. This provides roughness-dependent environment reflection,
not dynamic reflections, local probe volumes or general global illumination.
Translate lava with timed UV scroll/waves and controlled bloom. Original
HLSL/Cg and Unreal material graphs are not executed by the runtime.

Normalize the multiplayer TXT pair into 97 unique records; do not concatenate
the differing standalone map. Retain that map's differences and explicitly
adopt its warm lava light. Use the source-generated lava plane. Apply one 0.15
unit scale, calibrated from the legacy capsule height, to geometry, placement,
lights, spawns and collision. Apply RepX actor/local/mesh transforms to physics
only; the visual mesh already has its export orientation.

Use the same triangle data for Jolt movement, authoritative cover and client
prediction. Fresh character queries avoid hidden history during replay. Remove
the blockout floor/lift from original-map simulation. Protocol 12 includes a
nonzero fingerprint of collision, spawn and lava data; reject incompatible
scene snapshots before prediction. This is compatibility detection, not an
authentication primitive. Existing identity/admission/ownership policy remains.

## Validation and limits

See [FACTORY_RESTORATION.md](../FACTORY_RESTORATION.md) and the
[delivery report](../../reports/factory-restoration-2026-09-02/README.md).
Offline reproduction checks generated bytes and source hashes. Physics tests
cover all nine spawns, lower/upper support, deterministic replay, the open void
and wall-occluded hitscan with an unobstructed negative control. Network tests
cover original-map prediction/reconnect and two real GNS clients; dedicated
startup remains an actual executable gate.

Vulkan acceptance checks six inspected original-map references, material
metamorphic captures and all nine unchanged milestone-58 references. Validation
errors fail the graphics gates. The supplied video's first two minutes inform
manual appearance acceptance; its different cameras and mixed Factory/Dungeons
montage cannot serve as pixel-identical render targets.

One Minigun rig visual is deferred and one optional IronHellGoat glow texture
is absent from the source. Both have explicit diagnostics. Static pickup art
does not implement pickup mechanics. First-person weapons and characters remain
provisional. Samplers currently repeat; dynamic reflections, per-material
sampler modes, Unreal graphs, parallax, transmission and clear coat are outside
this material subset. Game distribution without the source tree remains later
work; the checked-in Factory manifest/probe use the existing source mount.
